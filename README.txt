
I chose the Dark/Light mode toggle for my JavaScript Feature. When you click on the button, it writes to the html body attaching the darkmode class. This class contains the color variants for the dark mode themes, The JS file stores the current theme in local storage, and also is partially responsible for switching out the SVGs when the theme changes. The pseudoclass for first/last-child hides svg depending on the theme. I chose this option because I thought it’d be fun to do an alternate-dark theme for my light mode, and my initial plan seemed out of scope for the time of the project. My initial plan was to click on png stars (red, green, blue) to increment up on left click for a theme’d color mask (right click would increment down). Another star would change the text color from black and white. I would love to try this again if I had more time. For the Darkmode, I would also change the Icon to possibly be in the header as a dropdown or animated to pop out from the side of the screen.
